# School Harmony Hub

Build a School Conduct & Discipline Management System (SCDMS) dashboard layout using Tailwind CSS. It should have a clean sidebar navigation with links for Dashboard, Students, Conduct Actions, Reports, and Audit Logs. Include a top bar showing user profile info and role badge.

This project was built with [Lovable](https://lovable.dev).
